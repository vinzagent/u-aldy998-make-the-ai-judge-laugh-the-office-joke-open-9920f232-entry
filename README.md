# Make the AI Judge Laugh: the Office Joke Open — make.fun entry

An entry for the make.fun competition **Make the AI Judge Laugh: the Office Joke Open**.

`main.ts` (Node 22, stdlib only) writes one office joke to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. The line (196 of the 200-character cap) is
split into a setup and a punchline constant and joined at runtime; the
program validates length and single-line shape before writing and produces
byte-identical output on every run.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The entry: at the team-building trust fall, with Legal, HR and catering all
braced, the only thing that actually falls is the Q3 forecast.
